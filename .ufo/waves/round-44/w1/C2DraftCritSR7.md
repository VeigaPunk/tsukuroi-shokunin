## Answers to the three questions

- **Does 'a device carries a scrub context exactly while `btrfs_scrub_dev` runs on it' hold for every return path?** In the "return path leaves nothing behind" sense, yes — every return of `btrfs_scrub_dev` (3094, 3110, 3116, 3125, 3135, 3144, 3155, 3240, 3247) exits with `dev->scrub_ctx` as it found it; post-attach paths always pass through the detach at 3222 first. In the literal biconditional sense, no — the context window [3159, 3222] is a strict subset of the function's execution (pre-attach validation; post-detach `need_commit` transaction commit, which is the only place a return happens after detach and where the function can block for a while). This is cosmetic for the progress ioctl (the work has ended by detach time) but the sentence as written overreaches.
- **Is the replace [inference] honest?** Yes. It is explicitly labelled, its line coordinates (701-703, 1265-1267) are verified correct against v7.2.11 `dev-replace.c`, and both call sites pass `is_dev_replace = true` on the source device. It is scoped ("not pinned") and does not claim more than it verified.
- **Is 'copies the arguments back only when it is 0' exact?** Yes — S240 ioctl.c:3141 gates the whole-struct `copy_to_user` on `ret == 0`; nonzero ret copies nothing. (Micro-corner: a failed copy returns -EFAULT.)

## Proposed replacement text (sentence 1, only the overreaching clause)

> In Linux v7.2.11 a device carries a scrub context exactly while a scrub or device-replace run is in progress on it: `btrfs_scrub_dev` refuses with `-EINPROGRESS` when `dev->scrub_ctx` is already set, attaches its context at scrub.c:3159 after all refusal checks and before any scrub work (scrub.c:3193, 3208), and detaches it at scrub.c:3222 once the work has finished; every pre-attach return path leaves `dev->scrub_ctx` untouched and every post-attach path reaches the detach before returning (the only post-detach code is the `need_commit` transaction commit, scrub.c:3232-3246), so a non-NULL `dev->scrub_ctx` implies a scrub/replace is running on that device at that moment.

No other sentence requires changes. All quotes (S242 scrub.c:3081, 3147, 3153, 3159, 3222, 3321, 3331, 3333, 3336; S240 ioctl.c:3139, 3141) are verbatim from the pinned files.
