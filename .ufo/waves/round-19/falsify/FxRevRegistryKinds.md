## Evidence

- **The gate validates an enum, not the kind's truth.** `8e5916360f2dfe7bc4eb4ba144081af555900116:tools/check-registry-coverage.py:203-214` reads `kind` from the registry row, emits `REGISTRY-KIND-INVALID` only if the declared text is outside `gate`, `probe`, and `library`, and checks verdict text only when that same declared field equals `gate`. It never inspects the entry point to derive or compare kind. The protocol's kind definition is behavioral: a gate returns a verdict, while a tool that cannot fail is a probe (`/home/vgpnk/Projects/kimi-shokunin/skills/shokunin/protocol/PROTOCOL.md:390-392`). Its registry schema names only `gate|probe` (`/home/vgpnk/Projects/kimi-shokunin/skills/shokunin/protocol/PROTOCOL.md:411-416`), while this checker additionally accepts `library`.

- **Minimal false-kind mutation that would pass (not applied):** in the `root-dac-correction` row at `8e5916360f2dfe7bc4eb4ba144081af555900116:SKILL.md:2067`, change only the Kind cell from `gate` to `probe`, preserving every other cell. This is false under the protocol definition: `evaluate()` in `8e5916360f2dfe7bc4eb4ba144081af555900116:tools/check-root-dac-correction.py:222-223` returns `FAIL` when its findings are nonempty and otherwise `PASS`; `run_gate()` supplies the evaluated result at `8e5916360f2dfe7bc4eb4ba144081af555900116:tools/check-root-dac-correction.py:264-283`, `emit()` returns `result.code` at `8e5916360f2dfe7bc4eb4ba144081af555900116:tools/check-root-dac-correction.py:231-233`, and the CLI returns it through `sys.exit(main())` at `8e5916360f2dfe7bc4eb4ba144081af555900116:tools/check-root-dac-correction.py:533-549`. The checker would accept the forged `probe` enum at `8e5916360f2dfe7bc4eb4ba144081af555900116:tools/check-registry-coverage.py:208`, skip the gate-only verdict test at `8e5916360f2dfe7bc4eb4ba144081af555900116:tools/check-registry-coverage.py:211-214`, still resolve the unchanged entry/self-test paths at `8e5916360f2dfe7bc4eb4ba144081af555900116:tools/check-registry-coverage.py:204-229`, and still count the tool as covered at `8e5916360f2dfe7bc4eb4ba144081af555900116:tools/check-registry-coverage.py:231-241`. **[INFERENCE]** Therefore that one-cell change would produce no finding.
