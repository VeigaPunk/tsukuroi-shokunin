   514	.SH "INSTALL/UPGRADE/REMOVE SCRIPTING"
   515	.sp
   516	Pacman has the ability to store and execute a package\-specific script when it installs, removes, or upgrades a package\&. This allows a package to configure itself after installation and perform an opposite action upon removal\&.
   517	.sp
   518	The exact time the script is run varies with each operation, and should be self\-explanatory\&. Note that during an upgrade operation, none of the install or remove functions will be called\&.
   519	.sp
   520	Scripts are passed either one or two \(lqfull version strings\(rq, where a full version string is either \fIpkgver\-pkgrel\fR or \fIepoch:pkgver\-pkgrel\fR, if epoch is non\-zero\&.
   521	.PP
   522	\fBpre_install\fR
   523	.RS 4
   524	Run right before files are extracted\&. One argument is passed: new package full version string\&.
   532	\fBpre_upgrade\fR
   533	.RS 4
   534	Run right before files are extracted\&. Two arguments are passed in this order: new package full version string, old package full version string\&.
   542	\fBpre_remove\fR
   543	.RS 4
   544	Run right before files are removed\&. One argument is passed: old package full version string\&.
   545	.RE
   546	.PP
   547	\fBpost_remove\fR
   548	.RS 4
   549	Run right after files are removed\&. One argument is passed: old package full version string\&.
   550	.RE
