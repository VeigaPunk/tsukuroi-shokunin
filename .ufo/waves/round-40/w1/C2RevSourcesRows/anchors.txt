# S224 asciidoc 58-95
     1		See CAVEATS for special notes regarding Path triggers. 'File' is a deprecated
     2		alias for 'Path' and will be removed in a future release.  Required.
     3	
     4	*Target =* <path|package>::
     5		The path or package name to match against the active transaction.
     6		Paths refer to the files in the package archive; the installation root
     7		should *not* be included in the path.  Shell-style glob patterns are
     8		allowed. It is possible to invert matches by prepending a target with an
     9		exclamation mark. May be specified multiple times, with subsequent
    10		matches overriding previous ones. Required.
    11	
    12	ACTIONS
    13	-------
    14	
    15	*Description =* ...::
    16		An optional description that describes the action being taken by the
    17		hook for use in front-end output.
    18	
    19	*Exec =* <command>::
    20		Command to run.  Command arguments are split on whitespace.  Values
    21		containing whitespace should be enclosed in quotes.  Required.
    22	
    23	*When =* PreTransaction|PostTransaction::
    24		When to run the hook.  Required.
    25	
    26	*Depends =* <package>::
    27		Packages that must be installed for the hook to run. May be specified
    28		multiple times.
    29	
    30	*AbortOnFail*::
    31		Causes the transaction to be aborted if the hook exits non-zero.  Only
    32		applies to PreTransaction hooks.
    33	
    34	*NeedsTargets*::
    35		Causes the list of matched trigger targets to be passed to the running hook
    36		on 'stdin'.
