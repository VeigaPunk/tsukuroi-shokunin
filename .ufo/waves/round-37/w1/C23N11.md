## 2. Precision assessment

2. **Option form / order** — short `-n 1` vs long `--lines=1`; `-n 1 -N` vs `-N -n 1`.

Absolute byte counts are journal-content-dependent (recorded `ext_plain_N` = 2882 bytes / 167 fields on 2026-10-23; today 2735 bytes / 160 fields — field set drifted). `"unchanged"` must mean relational equality, never an absolute magnitude.
4. **Separation from `-F`** — the same `-n N` truncates `-F`'s value list; the correction must table the two objects separately (third state), not one WORK row.

Precision verdict: the *correction target* is precise once these four axes are stated; the *current note text* states none of them explicitly (the identity exists only as matrix-cell sha equality, and line 48's prose covers only the `-F` side).
