# Method (what one script run does for each variant)
# ============================================================================
1. If absent, clone the lane --no-local into the sandbox workdir and disable the push URL.
2. git checkout --detach c8fcfbf6; git reset --hard c8fcfbf6; git clean -fd.
3. Apply the committed mutation patch (extracted with `git show 6de666c:<path>`, i.e. committed
   bytes, not the lane worktree) with `git apply --index`; for PathCopy perform the documented
   one-line substitution instead.
4. Verify the mutated file's sha256 against the seat's committed evidence; abort on mismatch.
5. Commit in the sandbox clone with `-c user.name=ctl -c user.email=ctl@sandbox`.
6. Run `git -c diff.algorithm=histogram -c diff.mnemonicprefix=true -c diff.colormoved=plain
   diff 9c89ff4f HEAD` and compare size and sha256 with the scratch file.
