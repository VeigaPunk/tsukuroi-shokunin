## Impacted axes and the smallest safe correction

- Adjacency (the C2 measurement). The count of 6 stands, but what it certifies is weaker than "anchored": findings 2-11 and 14 are padding moves the counter would not refuse. Calibration of counter claims is also affected: the PASS status on a register with failing rows (finding 12), and a crash reported as a count miss (finding 13).
- Tool bugs. The counter is pinned for this round, so these need a disclosure now and a fix in a later counter. Return anchored_rows 0, or exit 2, whenever the set of dict-row ids is not exactly IDS or any row is not a dict. Treat a non-string id as `id-unknown` before the province lookup. Accept only real table rows outside code fences, and allow optional indentation and an optional leading pipe. Split snapshot lines with `splitlines()`. Compare the digest case-insensitively.
- Rule gaps, for the L1 to disclose in the round-27 lesson. These are tradeoffs the judge should weigh. The tightenings, for a future rule: refuse a `lane_path` under `.ufo/`, under `corpus/knowledge/adjacency-*`, or under the snapshot directory. Require `sibling_path == PIN_PATH`. Require that LANE-GAP comes with a null lane side. Set a minimum quote length, for example 4 words. Refuse a quote window that contains a `#` line other than the heading. Cap the number of LANE-GAP rows. Make `sibling-unavailable` exit 2 or force a declared sibling repository, rather than counting snapshots nobody verified.
