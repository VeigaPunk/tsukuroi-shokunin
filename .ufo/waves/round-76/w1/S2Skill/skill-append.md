## Round 76 — journald retention decisions

Sources S318–S321; note `corpus/knowledge/journald-retention-plane-r76.md` (JD1–JD8; corrected note snapshot BD5A). This is a draft append for L1 integration, not an edit to SKILL.md. Axes: depth, operability, skill.

**Boundary:** detection and report only. Never run vacuum, rotate, flush, restart or config writes. Operator actions below are suggestions requiring separate operator approval and elevation where necessary, never actions executed by this lane. A permission failure is BLOCKED, not an invitation to sudo. Preserve the existing journal-empty BLOCKED rule (`SKILL.md:500-502`) and coredump counting distinction (`SKILL.md:2874-2882`): journal records are not stored core files. Commands below query the default host journal, not every namespace or remote journal. Successful reads do not prove complete visibility.

Commands C01–C10 are spelled out in the receipt table below; execute the listed commands for a symptom and retain their exits/output. Inspect active assignments in merged configuration, not commented examples. A missing message alone never establishes a cause.
