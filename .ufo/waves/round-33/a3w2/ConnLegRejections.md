## Proposed non-obvious move

**Affected axes: adjacency (depth), discernment. Move: make any future counted C2 claim carry a sourced *decision* per class row (not merely a definition or observation), and freeze a no-decision control (`CtlGlossary`-style) in the pre-data control set before data is taken.**

Evidence for the move: mori r33's CtlGlossaryA1 meets P-C1-A1 with 11 definitions and zero decisions, which is exactly the shortcut shape a boundary note is exposed to if its rows are only definitions. Tsukuroi's current C2 note (`corpus/knowledge/kill-oom-boundary-r33.md`) is exploratory and unmeasured, so §9 does not bind it today, but its rows are already sourced observations with [obs]/[inf] tags and wave-2 quote re-opens. Converting the retention/overlap cells into sourced decisions (owner + dated-event criterion) would make a glossary control fail, and freezing that control before data would close the gap mori's closure named (pre-data control set lacked a no-decision control). The cost is bounded (one control receipt slot per class, already mirroring the a3w1 pattern) and harms no axis: C1/operability is untouched, and the note remains exploratory until a counted claim is declared.

Risks: (a) adds work to an exploratory note that may never be counted; (b) if the decision criterion is chosen loosely, the control still passes. Mitigation: reuse the a3w1 control-receipt discipline (one score, no re-scoring) and require the no-decision control's receipt to bind a frozen sha before any data seat.

Verification: (1) wave-2 re-opens every quote/pointer in `kill-oom-boundary-r33.md` (already planned) and records SUPPORT/FAIL per row; (2) if C2 is ever promoted to counted, add a pre-data `CtlNoDecision` control receipt to the wave-1 control set and require `supported` rows to name a decision, mirroring `count-c1-a1.py`'s reading.
