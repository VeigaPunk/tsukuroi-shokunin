### Notes on the row

No run start time was recorded anywhere else: at `f8e3a8f` there is no `.ufo/waves/round-28/measure/` path at all.
- R2 is a mid-round state, not a permanent red: the first round-28 receipt commit will satisfy it. R1 and R3 cannot flip, because the committed declaration will always carry the disclosure and the same commit will always carry the counter change.

Round 28 satisfies the letter of that sentence against round-27 data while breaking its purpose, because the counter revision, its battery and the declared target are one commit, so no retained artifact orders the counter's B1-B7 rules before the 0-of-24 result they produce.
- What this row does not say. It does not say the declared value is wrong or that the disclosure is dishonest. C1's declared after-value is re-measured by `tools/mutants-adjacency-overlap.py --base <REV> --counter-rev <REV>` and re-run by wave seats; this row concerns only the ordering of declaration and observation, and no self-falsification occurred.
- Suggested criterion wording, if the lane admits one: a round's declaration commit precedes every run of its declared counting command, the first receipt for each claim is committed at a descendant of that declaration commit, and a run made before the declaration is recorded as development-only and is never the value the declaration states.
