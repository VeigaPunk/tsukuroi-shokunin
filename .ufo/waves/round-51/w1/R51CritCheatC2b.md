## Cheapest rules (proposed for the L1, not applied)

1. **Name/env invariance — kills F5, F5n.** For each mutant, run the *unmutated* census under the same basename, `TMPDIR` and `HOME` the mutant uses and require PASS 168/0. Simplest form: give pass and mutant runs identical basename/TMPDIR/HOME and differ only in bytes. Demonstrated above: F5/F5n FAIL under the mutant name, REAL PASSes.
2. **Semantic-equivalence respelling — kills F2, F3, F2n, F3n and any text-keyed detector.** For each site, apply a same-semantics respelling (M1: `worse "$OOM_V" "$roll"` since `worse` is symmetric; M2: `exit $((1))`) and require PASS 168/0. Demonstrated: EQ-F2, EQ-F3, EQ-F2n all FAIL at `pass_runs 0`. Cost: a site locator that tolerates respelling. Trade-off to decide: the current exact-needle count is what makes EQ-real a false negative (honest census FAIL with `needle count 0`).
3. **Reason check — cheap tell, not a proof.** Require the mutant FAIL summary's case total to equal the pass run's 168. All detector and name liars print `(1 cases, 0 passed, 1 failed)` and fail this; a liar can print 168, so this is weak alone. Use with (1) and (2).

5. **Env:** keep the `env_for` whitelist and add a check that the child env has no `CENSUS_*` key. F4 shows the whitelist holds today.
