usage: check-appended-notices.py [-h] (--revision REV | --selftest)
                                 [--branch BRANCH] [--registry REGISTRY]
                                 [--registry-from REV]

Read-only structural verifier for appended correction notices.

options:
  -h, --help           show this help message and exit
  --revision REV       7-64 hex commit landed and pushed on the selected
                       branch
  --selftest           hermetic fixture suite
  --branch BRANCH      landed branch for revision binding (default master)
  --registry REGISTRY  lane-relative registry JSON path
  --registry-from REV  read registry from this bound revision and compare its
                       claims
