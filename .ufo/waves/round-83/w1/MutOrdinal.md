## Method

1. Twenty single-clause mutants, generated by `mk_and_run.py` from the frozen file. Each is one `old -> new` substitution with `old` asserted to occur exactly once; the script also asserts the unified diff is one removed line and one added line (`changed_lines = 1` for all 20). Each mutant is its own file at `<S>/mut/Mxx/check-ordinals-r83.py` with its `DIFF.txt`.
2. Score (1): the mutant's own `--selftest`; rc != 0 is a kill.
3. Score (2): clone `lane` per mutant, check out REV, copy the mutant over `tools/check-ordinals-r83.py`, run `python3 tools/round83-battery.py --instrument r83 --revision REV`; any C2 leg not `pass` is a kill.
4. Survivors: a separating fixture (`sep/Mxx.md`) run against the original and the mutant, plus, where the revision path is involved, a bogus or no-SCORECARD repo. Each survivor is classified EQUIVALENT (no input changes the frozen verdict) or GAP (an input exists that the frozen selftest and C2 legs do not contain).

## Survivors: class and separating input

Every separating fixture below was run against the original and the mutant (scratch copies, not the lane). Original result is what the frozen tool prints; mutant result is what the mutant prints.

- **M11 — GAP, the judged axis.** Neither the selftest (11 cases, none uses `calibration`) nor C2.a–d reads calibration. Separator `sep/M11.md`:
  ```
  ## Round 9 — a
  calibration 8 → 9
  ## Round 9 — b
  calibration 8 → 8
  ```
  original rc1, one calibration finding (ordinals [8, 9]); mutant rc0 `examined 0`. A calibration contradiction is invisible to the frozen C2 battery. This is the strongest survivor.

- **M19 — GAP, revision exit code.** C2.d only exercises the absent-SCORECARD path at a binding revision; the bind-failure path is untested. Input: `--repo <lane> --revision 0000000000000000000000000000000000000000`. Original: rc2, JSON `finding: cannot-evaluate`, `E-REVISION-INVALID`. Mutant: rc1 with the same cannot-evaluate JSON (findings code for a non-evaluation, which the R82-V3 repair forbids).

- **M05 — GAP, arrow spelling.** The frozen selftest covers `→` and `->` only. Separator `sep/M05.md`: `depth 8 → 8` in block A, `depth 8 => 9` in block B. Original rc0 (clean); mutant rc1 (finding). `grep -c '=>' SCORECARD.md` at REV = 0, so C2.c cannot see it.

- **M07 — GAP, indented supersedes marker.** Frozen tool strips the line before matching `supersedes-ordinal:`; the selftest never indents. Separator `sep/M07.md`:
  ```
  ## Round 81 — measured
  | C1 | depth 8 → 9 |
  ## Round 81 — correction
    supersedes-ordinal: round-81 depth
  depth 8 → 8 — named correction, indented marker.
  ```
  original rc0 (the correction retires the earlier 9); mutant rc1 (earlier 9 unretired). `grep -cE '^\s+supersedes-ordinal' SCORECARD.md` at REV = 0.

- **M13 — GAP, non-round heading.** Frozen tool closes a round block at any `## ` heading. Separator `sep/M13.md`: `## Round 5 — a` / `depth 5 → 6` / `## Scratch notes (not a round)` / `depth 5 → 7`. Original rc0; mutant rc1 (the scratch section is read as round 5). Real tree is clean under the mutant (C2.c passed), so the shape is absent at REV.

- **M14 — GAP, round-number boundary.** Separator `sep/M14.md`: `## Round 9 — a` / `depth 8 → 8` / `## Round 9x — b` / `depth 8 → 9`. Original rc0 (`## Round 9x` is not a round heading and closes block A); mutant rc1 (`9x` is read as round 9).

- **M16 — GAP, digit boundary in Axes now.** Separator `sep/M16.md`: `## Round 9 — axes` / `Axes now: depth10, coverage9.` / `## Round 9 — b` / `depth 9 → 9`. Original rc0 (`depth10` yields no pair); mutant rc1 (`depth10` read as depth 1, contradicting 9).

- **M08 — GAP, output field only; verdict EQUIVALENT.** `examined` counts keys in the frozen tool; the mutant counts blocks. Separator `sep/M08.md`: `## Round 1 — a` / `depth 1 → 2` / `## Round 1 — b` / `depth 1 → 2`. Original rc0, `examined: 1`; mutant rc0, `examined: 2`. No leg and no selftest case reads `examined`.

- **M15 — EQUIVALENT.** The retired set is probed only with `(round, axis)` pairs whose axis came from `PAIR` or `AXES_NOW_PAIR`; both alternations are built from `AXES`. Keys outside AXES never match, so the filter is redundant for every input.

- **M20 — EQUIVALENT on the frozen predicate; GAP on diagnostic text.** With the check disabled, a revision with no SCORECARD yields empty text, which measures as no-round-blocks. Both paths print rc2 and `finding: cannot-evaluate`, so C2.d passes either way. Only `problems` differs: original `["absent-at-revision:SCORECARD.md"]`, mutant `["no-round-blocks"]`. The separating input is the `problems` string of a no-SCORECARD revision, which no leg checks.

## Gaps the frozen instruments do not reach (for the L1)

1. No selftest case and no battery leg for `calibration` (M11). The C2 claim is the calibration axis; the instrument cannot fail on a calibration contradiction.
2. Revision-path exit codes beyond the absent-SCORECARD case (M19, M20). C2.d covers one of the three cannot-evaluate routes.
3. Selftest has no indented supersedes, no `=>`, no non-round `## ` heading between round blocks, no round-number boundary, no digit-boundary Axes now (M05, M07, M13, M14, M16).
4. Battery is blind to the selftest-only items (M06, M09): `AXES_NOW` parsing and no-blocks cannot-evaluate. They are killed only by the selftest.

These are gaps in the instrument's coverage. None is a change to a frozen predicate; I did not propose or apply any patch. Each separator fixture above is one input that would turn the corresponding GAP into a kill.
