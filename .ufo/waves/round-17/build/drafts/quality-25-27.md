# Draft: QUALITY criteria 25–27 (round 17, not admitted)

25. **Next-boot verdicts from images (R17-IMAGE-NOT-CONFIG):** a next-boot verdict is derived from extracted boot-image contents (init root references, hook root paths, digests) and from the identity of the image actually booted, never from `/etc` configuration or package versions alone. Record each image path and digest. A configured hook path shows what was configured, not what a UKI will run. Lesson: `corpus/lessons/round-17.md` § Mistakes, R17-IMAGE-NOT-CONFIG. Outside pointer: none in `corpus/lessons/round-16-verifier-spotcheck.md` § 5; evidence basis `.ufo/waves/round-17/l1-capture/boot-chain-capture.txt`.

26. **Recheck command scope (R17-STEER-SCOPE):** a recheck procedure obeys the round's narrower command scope, not generic permission. Where a forbidden binary would answer the question (for example `pacman -Q`), substitute a read of the equivalent file (for example `/var/lib/pacman/local/*/files` or `/var/log/pacman.log`) and record the substitution with its path and date. A substitution is never reported as the forbidden command's output. Lesson: `corpus/lessons/round-17.md` § Mistakes, R17-STEER-SCOPE (the L1 `pacman -Q` mistake). Outside pointer: `corpus/lessons/round-16-verifier-spotcheck.md` § 5 item 3 (seat-scope deviations; QUALITY24 not yet shown able to fail).

27. **Gate revision binding (R17-JJ-REVISION):** a gate's `--revision` names a commit reachable from `refs/heads/<branch>` (and from `refs/remotes/origin/<branch>` when it exists), resolved as `<hex>^{commit}`. Symbolic revisions such as `HEAD`, `@`, or `@-` are rejected with E-REVISION-INVALID; commits outside the landed branch are rejected with E-REVISION-NOT-LANDED. Working-copy references do not name a landed branch commit [inf: in a jj-colocated repo, `@` may be unlanded]. Lesson: `corpus/lessons/round-17.md` § Mistakes, R17-JJ-REVISION. Outside pointer: none in `corpus/lessons/round-16-verifier-spotcheck.md` § 5; basis is the round-17 C3 revision-binding contract.
