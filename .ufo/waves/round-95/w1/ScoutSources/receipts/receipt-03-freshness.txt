--- 4. DOES THE HOST-BEHIND FACT CHANGE ANY ERA ANSWER? --------------------
The gate's era split is a constant, not a host reading:
  tools/check-limine-pins.py:104  VISIBILITY_ERA_SPLIT = (12, 9, 5)  # first upstream release
                                                                       # with the create_menu_tree() cut
  tools/check-limine-pins.py:193  era_b = version >= VISIBILITY_ERA_SPLIT
  tools/check-limine-pins.py:202  "visibility_era": "12.9.5+" if era_b else "pre-12.9.5"
  tools/limine-pin-battery-r95.py:321-326  the battery's own era_b() uses the same (12, 9, 5)
                                            tuple and the same comparison.

Consequences, measured from the code and the receipts above:

  (a) The ERA answers that C1 turns on are computed from the VERSION STRING the battery sends,
      never from the host's installed limine. The r95 family sends "999999999.9.9" explicitly:
        tools/limine-pin-battery-r95.py:1694  REFUSAL_DIGIT9 = "9" * 9 + ".9.9"
        tools/limine-pin-battery-r95.py:1715  _era_first_line_panic(c, REFUSAL_DIGIT9)
      and `pass_version` is True there, so the battery passes `--limine-version 999999999.9.9`
      (battery line 1981-1982) instead of probing. (999999999, 9, 9) >= (12, 9, 5) is True, so the
      family is era B, i.e. the first-line key is INVISIBLE and the answer is `panic`.
      => The host's 12.9.4 vs 12.9.6 does NOT change the r95 family's era or its expected answer.
      This is the same structure as the r94 ten-digit family, which pins c.version = "12.9.4"
      (battery line 1699-1700) for its healthy leg.

  (b) The host-coupled leg is the r94 `ERA-DEFAULT` family, which OMITS `--limine-version`
      (battery line 1637: `_era_first_line_panic(c, "12.9.4", pass_version=False)`; comment at
      battery lines 1983-1986) and therefore lets the gate probe the host's real `limine`.
      On THIS host the probe answers 12.9.4 -> era A -> the first-line key is VISIBLE -> the
      expected answer is `prompt`. If the host's limine were upgraded to 12.9.6, the same family
      would probe 12.9.6 -> era B -> `panic`, and the r94 expectation of `prompt` would need
      re-baselining. This is a recheck trigger, not a present error: the host is at 12.9.4 today.

  (c) Nothing in C1 or C2's frozen sentences depends on the host's installed limine version.
      C1's predicate names the version the FIXTURE carries (999999999.9.9); C2's predicate names
      the registry table in SKILL.md and the gate's own counts. The host's limine version enters
      only the ERA-DEFAULT family of the battery's roster.
