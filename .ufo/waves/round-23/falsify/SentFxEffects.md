# C2 — structured-edit audit authority is not an execution boundary

**Severity:** Moderate interpretation risk; no defect against C2's explicitly audit-only contract was found. Consequence becomes high if a consumer treats audit `PASS` or `structured_edit_mode: 1` as runtime authorization or proof of effects.

**Exploit path / concrete falsifier:** A consumer mistakes v2 audit authority for prevention or containment. A schema-v2 binding with an exact `edit_paths` target that is also listed in `read_paths` and `write_paths`, plus a recorded `edit` request using either accepted key shape, receives no finding: `classify_edit` checks only argument keys and literal target membership, then returns `[]` (candidate `tools/check-seat-bindings.py`, lines 119–130). `evaluate` processes records after receipt and sets `structured_edit_mode` to `int(code != 2)`; it does not mediate a tool call (lines 181–206). The selftest defines an empty trace as a clean case, and its `complete` flag is only shape-checked; thus a clean result cannot prove that no unrecorded request occurred (lines 167, 244–246). No test was run.

**Effect/read/host boundary:** Edit body values are opaque, and the path checks are lexical, not filesystem resolution: `local` rejects dot segments and spelling hazards but does not resolve symlinks (lines 33–36); `classify_edit` does not inspect body values or resolved referents (lines 119–130). [INFERENCE] If an authorized literal target is a symlink, the request audit alone cannot establish where an editor's effect lands. Nor does an `edit_paths` declaration or a recorded `read` prove bytes were actually read. Empty `commands`/`fetches` and a recorded denial for known forbidden tools are schema/audit rules, not permissions enforcement or a license for host actions. The preregistered C2 scope and checker `SCOPE` expressly disclaim native prevention, effects/reading proof, and universal trace completeness (preregister.json lines 37–44, 110–114; checker line 17); the policy likewise says the task API has no restrictive per-seat allowlist (structured-edit-r23.md lines 26–31).

**Impact:** The exact C2 claim remains a finite post-hoc audit-authority claim, not a runtime guarantee. Broadening its interpretation could leave an otherwise recorded request executable, or misrepresent an incomplete/unverified trace as evidence that an effect or read did not occur. No actual symlink, unrecorded event, or out-of-binding effect was established from the permitted evidence.

**Smallest in-scope remedy:** Preserve and surface the existing audit-only boundary wherever the result is consumed: `PASS`/`structured_edit_mode` means only that the supplied recorded requests were classifiable under the declared schema, not that requests were prevented, effects contained, reads proved, or host actions authorized. No seat-scoped remediation of runtime enforcement is available or authorized here; stronger assurance requires a real restrictive execution boundary and independently trusted effect/trace evidence.
