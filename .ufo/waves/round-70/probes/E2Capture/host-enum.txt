## 14. how each C2 field is derived (command -> output)
mounts    : awk '$3=="xfs"{print $1}' $M | sort -u | wc -l                 -> 2
present   : for each distinct source, test -d $SYS/<basename>; count yes       -> 2
absent    : mounts - present                                                  -> 0
unreadable: present dirs failing test -r/-x                                   -> 0
stats     : readable <dir>/stats/stats whose first line matches the regex      -> 2
error     : sum of find <dir>/error -type f | wc -l over mounts                -> 18
log       : sum of find <dir>/log -type f | wc -l over mounts                  -> 8
detail    : closed vocab tokens fired live                                     -> none

stats including the global file    : 3 (pollutes stats and breaks stats <= present)
