The host's mtime is the Last-Modified header that the stable mirror sent with the copy the host last downloaded. That header is the time the mirror wrote that object into the stable channel. It is not the time the Arch snapshot was taken.

A birth time therefore marks the start of the last successful download.

A not-modified reply sets condition-unmet with no bytes. The branch at lines 675-681 then deletes the temporary file and returns 1. The parent maps the child's 1 to a non-fatal 1 (lines 1035-1044).
