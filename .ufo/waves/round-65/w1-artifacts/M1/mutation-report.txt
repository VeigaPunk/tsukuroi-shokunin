===============================================================================
4. COVERAGE FINDINGS
===============================================================================
F1 (highest)  The suite cannot detect its own blindness. `ok = True` (M2) is a
   one-line change that leaves D1/D2/D3 all green while removing every
   assurance the selftest claims. No case INSIDE selftest() can close this,
   because the mutation is downstream of `results`. The closing detector must be
   a test-the-test: run the tool's selftest on a copy with a known-broken scan
   and require RED. Validated patch below (P1).

F2 The batch-completeness property (r62's three-findings red run) is held by an
   out-of-band revision run only. The fixture has a single ghost, so a
   findings-list truncation (M5) is invisible to `--selftest`. Validated patch
   below (P2): a three-ghost case makes both the count and the set internal to
   the suite.

F3 A green-only check kills 1/5. The r59 count rule ("count the cited paths,
   then write the count") is exactly the property M5 breaks; if the round's
   evidence for this gate is ever reduced to "PASS 4/4 at the final tree", the
   gate's remaining teeth are M3 only.

F4 Vacuous green for the live round. At 37c74e27 `--round 65` gives
   cited_paths 0 -> PASS, and M1 (allow-all) produces the byte-identical result
   (count 0, cited 0, rc 0). Until this round cites a `.ufo/waves/round-65/`
   file path in its own committed artifacts, the gate's green at the round's
   tree is green-by-emptiness and carries zero information. This is not a
   defect of the tool (it reports what the bytes name); it is a limit on using
   the round's own PASS as evidence.

F5 Honest limit already in the docstring: a receipt written but never cited is
   invisible. M5 shows the mirror case - a citation SET can be under-reported
   without any single citation being wrong, on exactly the shape (one ghost)
   the fixture used.

def mutate_selftest():
    """Test-the-test: a copy whose findings loop reports nothing must make
    --selftest go RED.  Guards the suite against silently asserting nothing
    (a blanket `ok = True` in selftest() cannot be caught from inside it)."""
    import shutil
    mine = Path(__file__).read_text()
    broken = mine.replace(
        "    findings = sorted(p for p in cited if p not in paths)\n",
        "    findings = []  # injected allow-all mutant\n")
    if broken == mine:
        print(json.dumps({"mutation_selftest": "CANNOT",
                          "error": "mutation anchor not found"}))
        return CANNOT
    tmp = tempfile.mkdtemp(prefix="cited-receipts-mutant-")
    rc = None
    try:
        copy = Path(tmp) / "mutant.py"
        copy.write_text(broken)
        proc = subprocess.run([sys.executable, str(copy), "--selftest"],
                              stdin=subprocess.DEVNULL, stdout=subprocess.PIPE,
                              stderr=subprocess.PIPE, env=clean_env(), timeout=300)
        rc = proc.returncode
    finally:
        shutil.rmtree(tmp, ignore_errors=True)
    killed = rc != 0
    print(json.dumps({"mutation_selftest": "PASS" if killed else "FAIL",
                      "mutant_exit": rc}, indent=1))
    return PASS if killed else FAIL
