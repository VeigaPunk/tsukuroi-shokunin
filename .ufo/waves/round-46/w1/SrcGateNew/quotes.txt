72:        <i>/proc/</i>pid<i>/fd/</i>
73:               This is a subdirectory containing one entry for each file
74:               which the process has open, named by its file descriptor,
75:               and which is a symbolic link to the actual file.  Thus, 0
76:               is standard input, 1 standard output, 2 standard error, and
77:               so on.
78: 
79:               For file descriptors for pipes and sockets, the entries
80:               will be symbolic links whose content is the file type with
81:               the inode.  A <a href="../man2/readlink.2.html">readlink(2)</a> call on this file returns a
82:               string in the format:
83: 
84:                   <i>type</i>:[<i>inode</i>]
85: 
86:               For example, <i>socket:[2248868]</i> will be a socket and its
87:               inode is 2248868.  For sockets, that inode can be used to
88:               find more information in one of the files under <i>/proc/net/</i>.
