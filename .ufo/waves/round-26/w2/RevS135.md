5. [obs] FAILS: the teaches cell misstates the increment rule. SOURCES.md:141 says Unexpected Power Losses "increments only when main power is lost before the controller reports it is ready to be powered off." The excerpt says at line 239: "This count shall be incremented if, and only if, main power is lost when:". Branch a, lines 245-246, reads "the controller does not report it is ready to be powered off (i.e., the CSTS.SHST field is not set to 10b)". Branch b, lines 247-256, reads "shutdown processing was reported as in progress or was reported as complete" and "the value of the CSTS.SHST field was set to 01b or 10b". Branch b also requires that the media was not in a shutdown state because of an out-of-band Admin command with the Ignore Shutdown bit set (lines 249-256). Branch a equates CSTS.SHST 10b with ready to be powered off, so branch b covers an increment after the controller has reported ready. The teaches cell's "only when ... before ... ready" drops branch b. The row's own anchor cites excerpt lines 237-258, and those lines contain branch b. No Gate quote covers lines 239-256, so the increment rule has no Gate record. Suggested wording [inf]: the counter increments if, and only if, main power is lost while the controller has not reported ready to power off, or while a shutdown is in progress or complete and an out-of-band Ignore Shutdown command has kept the media from shutting down.
