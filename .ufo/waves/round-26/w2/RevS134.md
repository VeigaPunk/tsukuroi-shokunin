## Method

Ordinary means only: plain `curl` of public URLs, no browser, no challenge bypass. The row URL (github.com blob page) returns HTTP 200 to plain curl; the bytes were pulled from raw.githubusercontent.com at both the tag and the commit the anchor pins. `git show` against the lane at 7dfea9244a84a0e2439f0698e54491e5d7b7c467 was used read-only to confirm the committed snapshot and to read SOURCES.md as pinned. All comparison was byte-level; no project language server answers this fetched upstream file, so LSP checks were not applicable and text/byte comparison is the semantic instrument here.
